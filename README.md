Тестовое задание — обработка данных о продажах

Описание проекта

Программа обрабатывает CSV-файл с данными о продажах и формирует ежедневный отчёт по каждому артикулу (SKU).

Требования

* Подсчёт количества уникальных заказов по каждому SKU и дате.
* Включение отменённых заказов в количество заказов.
* Расчёт выручки только по заказам со статусом delivered.
* Исключение точных дубликатов заказов.
* Сортировка результата по SKU и дате.

Используемые технологии

* Python 3.12
* Стандартная библиотека Python (csv, decimal, argparse, unittest).

Внешние библиотеки не требуются.

Структура проекта

* main.py — основная программа.
* tests/test_main.py — автоматические тесты.
* sales.csv — входные данные.
* daily_by_sku.csv — итоговый отчёт.

Запуск программы

Поместить исходный файл sales.csv в папку проекта и выполните:

python main.py --input sales.csv --output daily_by_sku.csv

Запуск тестов

python -m unittest discover -s tests -v

Все 4 автоматических теста успешно пройдены.

Результаты обработки

* Входных строк: 13 858.
* Уникальных заказов: 13 798.
* Дат: 56.
* Артикулов SKU: 12.
* Строк итогового отчёта: 631.
* Итоговая выручка: 10 276 540.

Особенности обработки данных

* Точные дубликаты заказов исключаются.
* Конфликтующие записи с одинаковым order_id вызывают ошибку.
* Статусы нормализуются с учётом регистра и пробелов.
* Варианты canceled и cancelled обрабатываются как отменённые заказы.
* Отсутствующее количество допускается только для отменённых заказов.
* Для расчёта денежных значений используется Decimal.
